# ios/contract: shared fixtures

JSON fixtures that both the iOS tests and (one day) the Android tests read. One directory per area, one owner per directory
(`scripts/ownership.tsv`).

## Rules

- **`_source` on everything (D59).** Every fixture has `_source` at the top level, or on every entry of its entries array.
  Its value is `android:<path>:<line>@<sha>` (the assertion line of the Android test, or the code line) or `ios:<Dn|Qn>`
  for rows that exist only on iOS. A `_source` with no Android line is an iOS decision, never an unchecked claim.
- **Never hand-typed from memory (D103).** Values are transcribed from the cited Android line. `routes/` and `errors/` are
  generated by `scripts/gen-contract.sh` from the Android source at the baseline SHA.
- **Verified by `scripts/source-check.sh` (D103).** Every `android:` source must name the baseline SHA, the file must exist at
  that SHA, and the line must exist and not be blank.
- **Values, not just lines (D134).** A source may carry `_expect`, a list of literals (the code, a number, `Verb.READ`,
  `flag = true`). Every literal must occur within +-8 lines of the cited line. `_expect` is required on the rows of
  `pipeline/cases.json`, `gate/notify-outcomes.json`, `gate/approve-gesture.json`, `errors/error-codes.json` and
  `routes/route-flags.json` that cite Android. `scripts/contract-drift.sh` repeats the check against the Android tip and
  prints `DRIFT <file> <entry>` warnings (warn only).
- **Vendored files (D117).** A file under `**/vendored/` is a byte copy of an Android file. It needs a sidecar
  `<name>.source.json` with `_source` and the git blob id, and `source-check.sh` compares the bytes with `git show`.
- **example.com only.** Any address in a fixture is `@example.com`; `dod.sh` fails on any other.
- **No index file.** `ContractTests` globs `ios/contract/**/*.json`.

## Agreement is one-sided

Agreement is checked from the iOS side only until Android adopts the fixtures (owner question OQ6). Android does not read these
files today. The named follow-up for Android reading them is `P-ANDROID-CONTRACT` (OQ9).

## Areas written by T0

| Directory | Content |
|---|---|
| `routes/routes.json` | method and path of the 37 templates plus the exempt set `{POST /audio/{cue}, POST /tts}`, from `HelpContractTest.PINNED_ROUTES` |
| `routes/route-flags.json` | verb, describe, plugin and every flag of each route, with `_source` at its declaration and `_expect` |
| `routes/routes-ios.json` | the iOS overlay: routes that answer 501 `not_supported_on_ios` and their reasons |
| `errors/error-codes.json` | every code with its status; `listed:false` codes are emitted by Android but missing from `ErrorCodes.kt` (D106) |
| `core/ip-normalisation.json` | vectors for `NormalizedIP.parse` (D119) |
| `tokens/contrast-pairs.json` | the WCAG pairs the palette tests assert |
